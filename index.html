Personal-use application

Secretary Calendar

A private Google Calendar connection that lets the account owner's personal assistant tools put agreed meetings and tasks on the owner's own calendar.

What it does

The owner runs a small set of assistant tools on their own computer. When one of the owner's emails or chats mentions a meeting, a task, or a change to an existing plan, a local tool adds, updates, or cancels the matching event in the owner's Google Calendar and records what it did.

Google Calendar access

The connection requests two permissions: to view the owner's calendars, so it can find an existing event before changing it and avoid creating duplicates, and to manage events, so it can create, update, and delete them. It cannot change calendar settings or sharing.

This application is for its owner's personal use. It is not a public service and does not accept other users or any data through this website.
